# The Workbench — vertical system-design series

Long-form vertical explainers (1080×1920, ~2–2.5 min) where an abstract system
is rendered as **one tangible machine**, and the video is that machine changing
state.

> **Channel name is unresolved.** Currently *The Java Sundaresan*, chosen before
> the host became Dr. Sparks. See the open question at the end of
> `brand/CHARACTERS.md`.

## Read in this order
| File | What it settles |
|---|---|
| `brand/BRAND.md` | Name, art direction, palette, type, logo rules |
| `brand/CHARACTERS.md` | Dr. Sparks, the mascot, the dynamic between them |
| `brand/FORMAT.md` | Frame layout, HUD, captions, pacing — from reference analysis |
| `PRODUCTION.md` | How an episode actually gets made |
| `episodes/ROADMAP.md` | The episode chain |

## The two rules everything hangs off
1. **One machine per episode.** Pick the physical metaphor *before* writing a
   word. Then write the script as operations on that object. Nothing is ever
   explained in the abstract.
2. **Every episode breaks what the last one built.** Each video ends on the
   failure the next one solves, so the feed is a chain, not a pile.
