# Cast

Two characters. They are the format — the reference videos are single-narrator
monologues, and the dialogue is what makes this ours.

**Build order: characters first, then the brand and logo are derived from
them.** The logo is not an abstract mark — it is the host's portrait. His head
has to survive being shrunk to a 40px avatar, so the design is driven by
silhouette before anything else.

---

## DR. SPARKS — the host
**Status: concept locked. Cartoon redraw in progress.**

**Role:** explains. An old engineer running a secret project deep in a forest,
off the grid on purpose, who treats every system design problem as something he
has personally already blown up at least once.

**Spec (from the design sheet):**
| | |
|---|---|
| Age | 68, give or take |
| Title | Chief Engineer *(unlicensed)* |
| Specialty | Improbable systems |
| Tool of choice | Whatever's closest |
| Location | Somewhere north of nowhere |
| Project | H.E.LIOS — off the books |
| Motto | *"If it's stupid and it works, it ain't stupid."* |

**Design:** explosive white hair in a few big spiky shapes around a bald crown.
One huge wide eye, one squinting — lopsided manic grin. Big simple white
wedge beard. Brass welding goggles pushed up on the forehead as a bold solid
bar. Olive canvas field jacket, clipped tools, a coil of cable over one
shoulder. Fingerless gloves, chunky boots. Skinny, hunched, long bony fingers.

**Avatar test — PASSED at 40px.** The three shapes that carry him are the
**white hair halo**, the **brass goggle bar**, and the **white beard wedge**.
Those three must never be removed, recoloured, or broken up. Facial detail is
expendable at small sizes; those three shapes are not.

**Staging:** lower-LEFT of frame, full body, small (~1/5 frame height). Three
poses only: *cackling* (arms spread), *pointing* (explaining), *unimpressed*
(arms folded, flat stare). Never walks. Never overlaps the diagram.

**Voice:** short declarative sentences. Real numbers, never adjectives —
"latency goes to four seconds", not "it gets really slow". Names the real term
once, plainly, so it's searchable. Delighted when something breaks. Never
hypes, never says "let's dive in".

## THE MASCOT — being redesigned
**Status: scrapped, pending redesign.**

The first pass was *Seeti*, a South Indian pressure cooker. Dropped along with
the original host concept. Sheet kept at
`assets/characters/seeti-sheet-v1.png` for reference only.

**What the next mascot must keep — these were the good parts:**
1. **It is a live gauge.** Its physical state encodes system load, so the
   audience reads the system's health off the mascot without being told. The
   pressure-cooker states were: idle → healthy → saturating → overloaded →
   failed (lid pops, goes grey).
2. **It is an object, not an animal.** An object from the host's own workshop
   is funnier, more ownable, and ties to the forest-lab world.
3. **It asks the dumb question.** It says what a junior engineer would actually
   say — wrong but reasonable. The one joke per episode belongs to it.
4. **It breaks the machine at the end of every episode**, and that break is the
   next episode's cold open.

## The dynamic
The mascot proposes the obvious wrong fix. Dr. Sparks explains why the system
doesn't work that way. The mascot then breaks it in a *new* way.

**Hard rules:** Sparks never insults the mascot. The mascot is never stupid,
only fast. Neither addresses the camera until the final beat.

## OPEN QUESTION — the name no longer fits
The channel is currently named **The Java Sundaresan**, chosen when the host
was a South Indian engineer with a filter coffee. The host is now an old forest
recluse. The name and the character now point in different directions.

Resolve one of two ways:
- **Keep the name**, and treat it as the project's name rather than the man's.
- **Rename** to fit Dr. Sparks and the forest lab.
